让你的 RAG 真正在生产环境里跑起来

其他语言: English · Français

在 YouTube 上观看 ↗全部视频

一段简短实用的讲解，讲清楚到底是什么让检索增强生成（RAG）系统在生产环境里真正好用，而不只是演示好看。五条来自真实生产经验的教训。

你将学到：

  • 为什么在动手调整检索之前，记录每一次交互并收集点赞/点踩反馈，是你能做的投入回报最高的改动。
  • 为什么更大的上下文窗口不能取代检索，以及它始终解决不了的四件事：成本与延迟、访问控制、时效性，以及可追溯性。
  • 为什么一个检索通道永远不够，以及分块向量、摘要向量、全文检索和图检索各自如何弥补另一个的盲区。
  • 如何阅读自己的失败案例，用大模型归类，然后把一个界定清楚、可核实的问题交给 Claude Code 或 Codex 这样的编程 Agent，而不是含糊地让它"把 RAG 变好"。
  • 一份提示词，让你自己从零搭建整条四通道流水线。
