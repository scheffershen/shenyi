RAG 安全：在线测试租户边界｜第 15 课

其他语言: Français

在 RAG Formation 第 15 课中，我们转向安全——防止聊天机器人向错误的用户暴露文档，或泄露机密与客户数据。

如果系统泄露了不该泄露的内容，其他一切都没有意义——验证边界是否存在的诚实方法，不是先假定它存在，而是在线实际测试。这套系统的每个请求都有一个 workspace 字段，很容易让人以为它就是租户边界。用同一个问题和两个不同的 workspace 值调用 API 两次，然后观察真正发生了什么变化：图谱信号发生了变化——因为 LightRAG 确实按 workspace 做了范围隔离。向量搜索和全文搜索完全没有变化，因为它们从一开始就没有收到这个字段。

这不是假设性的漏洞；你可以用两个 curl 调用亲眼看到它。旁边还有另一个应该直接阅读、而不是想当然的事实：这个 API 的 CORS 策略允许来自任何地方的请求。这不是需要另行验证的风险，而是一行值得读懂的代码。
