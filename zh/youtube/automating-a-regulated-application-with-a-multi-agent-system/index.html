用多智能体系统自动化一个受监管的应用

其他语言: English · Français

在 YouTube 上观看 ↗全部视频

一个受监管的应用，成本很少花在敲代码上。花在岗位上：七个阶段，七次交接，每个人都在等上一个人。花在文档上：最后才写，凭记忆写，谁还在就谁写。花在审计上：一个当时不在场的人，要还原出谁验证的、谁决定的、证据是什么。

这条教程讲怎么把每一个岗位交给一个 agent，同时在每一道关卡上留一个人。十个 Claude Code agent、三个 skill 和一个 workflow 脚本，把一个小的 Symfony API 从需求文档做到验证档案，再从日志和需求收件箱做维护。编排者从不写代码。tester 从不读 diff。verifier 每次从零开始。tag、merge 和 push 永远归你。

四章：受监管应用的典型流程（三条流程、七个阶段）；TicketFlow 演示（构建、维护、发布三条流程，每条一张图）；基本概念（Claude Code 里的 skill、agent、workflow 各是什么）；以及怎么从你自己的流程出发，搭出你自己的 skill 和 agent。

2026 年 10 月 15 日，一个全新的会话在演示项目上只敲了 /improve，做到了这些：两轮，修了三个 bug，交付了两条功能需求，提了八个决定并都得到回答，每个事项第一次验证就通过；第一轮 27 分钟，第二轮 9 分钟，发布 10 分钟。数字都在教程仓库里。
