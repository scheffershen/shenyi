文本分块与文档结构

RAG Formation 课程仍在开发中；这份资料可用于自主学习和练习。

One-line rule

Change one window setting, measure whether the fact and source identity stay together, then test the hypothesis with a separate live retrieval evaluation.

一句话规则：一次只改一个窗口参数，测量“事实与来源身份是否同在”，再用独立的线上检索评估验证假设。

Glossary

TermMeaning中文
Source windowA repeatable, bounded slice of synthetic Markdown used in the offline lab.源窗口：用于离线实验的、可重复生成的合成 Markdown 片段。
Chunk sizeThe maximum number of characters allowed in one source window.窗口大小：一个源窗口允许的最大字符数。
OverlapCharacters copied from the end of one window into the next.重叠：从前一窗口末尾复制到下一窗口的字符。
Co-locationThe expected reference and every required fact term appear in the same window.同位：预期文档编号和所有必需事实词同时出现在同一窗口。
Proxy metricA directional signal—not a live retrieval or answer-quality result.代理指标：方向性证据，不是线上检索或答案质量结果。

Controlled experiment card

StepDoDon't claim
BaselineRun q24 with 280 characters and 40 characters of overlap.That this is the best production setting.
One changeKeep the overlap at 40 and rerun q24 with 420 characters.That several changes caused the result.
MeasureCompare the co-location count/rate and the readable window text.That the live index has improved.
VerifyReindex the isolated demo, then run the retrieval evaluation again.That a source-window proxy can replace evaluation.

实验卡：先在 280/40 下建立基线；只把窗口改为 420；比较同位数量/比例和窗口文本；最后在隔离演示环境中重新索引并重跑检索评估。

Commands and conclusion frame

cd demo
python3 chunk_lab.py --question q24 --window-chars 280 --overlap-chars 40 --output-dir reports/lesson-06-baseline
python3 chunk_lab.py --question q24 --window-chars 420 --overlap-chars 40 --output-dir reports/lesson-06-larger-window

Conclusion frame: “With ___ characters and ___ overlap, ___ of ___ windows kept the required fact and source identity together. This supports the hypothesis that ___. It does not prove live retrieval quality; next, I would reindex and run the retrieval evaluation again.”

结论句式：“当窗口为 ___ 字符、重叠为 ___ 字符时，___ / ___ 个窗口同时包含必需事实和来源身份。这支持 ___ 的假设；它不能证明线上检索质量。下一步是在隔离环境中重新索引并重跑检索评估。”
