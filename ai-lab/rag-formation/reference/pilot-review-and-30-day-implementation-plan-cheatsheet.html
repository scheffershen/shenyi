Reference sheet

Pilot review and 30-day implementation plan

The guided RAG Formation course remains in development; this reference is available for self-directed practice.

One-line rule

A pilot is not ready just because the demo sounds fluent; it needs clear quality, safety, and operational gates.

一句话规则：演示看起来流畅并不代表试点已经就绪；就绪需要明确的质量、安全和运维门槛。

Core terms

TermMeaning
Readiness gateA go/no-go decision based on clear quality, safety, performance, and operational thresholds.
Highest-value fixA change chosen because it addresses an important measured failure—not because it is fashionable.
Pilot scopeA limited user group, corpus, and workflow with known risks and success criteria.

Evidence card

NeedRecordDon't claim
BaselineCommand, configuration, observed resultThe baseline is a target.
ChangeOne hypothesis or decisionYou can tell what caused the result when several things changed.
MetricCompare the current report with the baseline; mark each readiness criterion pass, fail, or unmeasured.One metric tells you everything about quality.
SafetyA failure and a regression caseA fluent answer proves the system is reliable.

证据卡：记录基线、一次改动、指标和安全回归；不要把单一指标等同于整体质量。
