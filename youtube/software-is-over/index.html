Software is over: when code stops being scarce, what becomes scarce instead?

Also in: Français · 中文

Watch on YouTube ↗All videos

In October 2026, an open-source project picked up 20,000 GitHub stars in a single day. The same month, one developer cloned seven Adobe apps with AI. Back in May, the former CEO of Outreach hung a "Software is over" banner outside the biggest SaaS conference in the world.

Is software over? Not quite. What is over is software as an asset. Four points in under five minutes: speed explodes, code becomes disposable, core systems stay durable, and three things become scarce once code no longer is: the spec, the data, the workflow.
