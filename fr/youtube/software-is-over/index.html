Software is over : quand le code n'est plus rare, qu'est-ce qui le devient ?

Aussi en: English · 中文

Regarder sur YouTube ↗Toutes les vidéos

En octobre 2026, un projet open source a pris 20 000 étoiles sur GitHub en une journée. Le même mois, un développeur seul a cloné sept logiciels d'Adobe avec de l'IA. En mai, l'ancien patron d'Outreach a accroché « Software is over » devant la plus grande conférence SaaS du monde.

Le logiciel, c'est fini ? Pas exactement. Ce qui est fini, c'est le logiciel comme actif. En quatre points et moins de cinq minutes : la vitesse qui explose, le code qui devient jetable, les systèmes cœur qui restent durables, et les trois choses qui deviennent rares quand le code ne l'est plus : la spec, les données, le workflow.

Commentaire épinglé (précisions)

  • ⚠️ « Moins de deux semaines entre deux modèles » vient du décompte d'unbenchmark.com (4 / 15 / 42 / 39 modèles OpenAI + Anthropic). Avec un autre périmètre (versions majeures seulement), SemiAnalysis arrive à environ 51 jours. Tout dépend de ce qu'on appelle une sortie.
  • Les 285 milliards de dollars sont la capitalisation effacée sur les logiciels, services financiers et gestion d'actifs en quelques jours après le 3 février 2026 ; Thomson Reuters a perdu plus de 16 % ce jour-là.
  • « Marché minimum viable : une personne » et « serviette en papier » sont les formules d'Addy Osmani.
  • Le classement applicatif / systèmes cœur et les trois actifs (spec, données, workflow) sont la thèse de la vidéo, pas une citation.
