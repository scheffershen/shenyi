One-line rule

A larger top-k can hide a retrieval failure by adding noise; it does not diagnose the problem.

一句话规则：扩大 top-k 只会用噪声掩盖检索失败，并不能替代真正的诊断。

Core terms

TermMeaning
Query normalizationTurning a user’s question into useful search forms: the original question, extracted document IDs, normalized acronyms, or translated terms.
RerankingReordering the first set of candidates using stronger relevance signals, such as exact identifier matches, metadata, or a cross-encoder.
DeduplicationMerging repeated chunks from one document so the evidence budget holds independent support.

Evidence card

NeedRecordDon't claim
BaselineCommand, configuration, observed resultThe baseline is a target.
ChangeOne hypothesis or decisionYou can tell what caused the result when several things changed.
MetricRecord the expected source, baseline hit state, one changed query form, and the same metric after the change.One metric tells you everything about quality.
SafetyA failure and a regression caseA fluent answer proves the system is reliable.

证据卡：记录基线、一次改动、指标和安全回归；不要把单一指标等同于整体质量。
