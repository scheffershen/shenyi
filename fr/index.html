PROJET 01 — IA / RAG

Système RAG à recherche hybride pour la qualité pharmaceutique

Assistant RAG à recherche hybride indexant la documentation qualité interne (procédures, analyses de risques, questionnaires d'audit et de qualification des prestataires) d'un groupe pharmaceutique, avec un wiki de graphe de connaissances généré automatiquement et un agent IA d'extraction et de réponse aux questionnaires.

884 documents indexés (868 réussis) dans un pipeline de recherche vectorielle + mots-clés + graphe, avec extraction automatique de 6 673 entités sur 425 pages de wiki.

  • Python
  • Qdrant
  • Meilisearch
  • LightRAG
  • FastAPI
  • Serveur MCP
  • Ragas

PROJET 02 — IA MULTI-AGENTS

Assistant de code IA multi-spécialistes

Assistant multi-agents sur mesure qui route les questions des développeurs et du support sur une large base de code Symfony vers 12 domaines spécialisés (bugs, usage d'API, configuration, sécurité/RGPD, cadrage de fonctionnalités), avec des réponses obligatoirement sourcées et fondées sur des preuves.

Est un copilote de navigation IA sur une base de code Symfony 6.4 en production de 800+ fichiers et 180+ entités.

  • Python
  • SDK OpenAI
  • Serveur MCP
  • tree-sitter (AST PHP)
  • NetworkX
